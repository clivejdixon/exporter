    Export

    Downloads go to your browser's default download folder, one file per selected flow. The dependency list is read from the flow's manifest, the same data that is in the exported YAML. Tick the objects you want, then use Download list (.csv) or Export to Terraform. Each selected flow gets its own <flowname>.tf; keep each .tf in its own folder when you run it. Task diagram draws each task of the selected flow and highlights the blocks that use the objects ticked in the list below (set each group's colour with its round swatch). Download it as SVG or PNG.
